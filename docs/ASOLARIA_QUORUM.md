# ASOLARIA tri-vantage quorum

Completion requires three declared seats: executor evidence, an independent
verifier verdict and a completion audit. Every seat records agent address,
context hash, prompt hash, seed, source SHA, policy hash, criteria references
and evidence handles.

The validator rejects a shared identity/context/seed, stale evidence, timeout,
missing receipts, incomplete acceptance-criterion traceability or absent clean
control. A unit result cannot satisfy an E2E criterion by relabeling it.
Quality emits the non-terminal receipt; the Loop Completion Auditor and Oracle
retain terminal authority.

The contract is ready for Loop Work Gap Ledger integration. Full certification
still requires real independent executions, seeded defects, clean controls and
freshness invalidation in the authoritative runtime.
